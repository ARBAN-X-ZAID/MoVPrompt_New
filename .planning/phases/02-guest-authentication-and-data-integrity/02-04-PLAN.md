## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser blob metadata → API | MIME, size, checksum and identifiers are untrusted declarations. |
| API → private S3 | Owner authorization and canonical key control write/read/sign operations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-15 | Spoofing | Project/asset identifier | high | mitigate | Session owner plus project/asset tuple authorization. |
| T-02-16 | Tampering | Media metadata | high | mitigate | Magic bytes, streamed size, SHA-256 and HEAD metadata agreement. |
| T-02-17 | Information disclosure | Signed URL/object key | high | mitigate | Response-only short-lived URL and generic denied response. |
| T-02-18 | Denial of service | Partial uploads | medium | mitigate | Resumable per-asset checkpoint and later 24-hour cleanup job. |
| T-02-19 | Elevation of privilege | URL refresh | critical | mitigate | Owner repository lookup and namespace assertion before signing. |
| T-02-SC | Tampering | Package installation | high | mitigate | Existing storage/browser dependencies only. |
</threat_model>
