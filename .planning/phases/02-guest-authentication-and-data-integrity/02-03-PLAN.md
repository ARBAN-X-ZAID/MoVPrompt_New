<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Auth environment → public capability | Secrets and policy must be reduced to safe method/policy values. |
| OAuth callback → session/claim | Provider state becomes an owner session able to claim a local intent. |
| Browser next/reset → navigation | Untrusted return input can redirect or loop. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-10 | Spoofing | OAuth callback | critical | mitigate | Better Auth state/session semantics plus deterministic invalid-state tests. |
| T-02-11 | Tampering | Verification policy | high | mitigate | One typed explicit policy consumed by auth/API/web. |
| T-02-12 | Repudiation | Social callback replay | high | mitigate | Same claim intent/idempotency and concurrent provider-stub proof. |
| T-02-13 | Information disclosure | Provider capability | high | mitigate | Method names/policy only; redaction assertions. |
| T-02-14 | Elevation of privilege | Test stubs | critical | mitigate | Test-only injection seam that production composition rejects. |
| T-02-SC | Tampering | Package installation | high | mitigate | No provider/test dependency addition. |
</threat_model>
