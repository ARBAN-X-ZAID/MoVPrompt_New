| Boundary | Description |
|---|---|
| Source replacement → project version | Untrusted source data changes immutable project state. |
| Cached/project output → UI | Stale media can be misrepresented as current campaign output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-25 | Tampering | Source fingerprint | high | mitigate | Canonical server normalization and configuration-bound idempotency. |
| T-02-26 | Repudiation | Source replay | medium | mitigate | Immutable child version plus operation key/request ID. |
| T-02-27 | Information disclosure | Cross-owner source asset | high | mitigate | Owner/version/asset tuple validation and generic rejection. |
| T-02-28 | Information disclosure | Stale media projection | high | mitigate | Compatibility check and no sample/source/output fallback. |
| T-02-29 | Denial of service | Offline retry loop | medium | mitigate | Explicit user retry only and retained local draft. |
| T-02-SC | Tampering | Package installation | high | mitigate | Existing web/API dependencies only. |
</threat_model>
