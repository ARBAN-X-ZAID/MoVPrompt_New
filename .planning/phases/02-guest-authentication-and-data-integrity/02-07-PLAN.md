## Trust Boundaries

| Boundary | Description |
|---|---|
| Cleanup worker → private object deletion | Delayed/replayed jobs can destroy customer media without a final-state recheck. |
| Admin migration URL → CREATE/DROP DATABASE | A script guard failure could target shared data. |
| Restricted DB role → owner tables | RLS must work without superuser/bypass privileges. |

| T-02-31 | Repudiation | Cleanup attempts | high | mitigate | Durable audit state, sanitized codes and pg-boss job/request IDs. |
| T-02-32 | Denial of service | Cleanup retry | medium | mitigate | Idempotent not-found success and bounded backoff. |
