<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Authenticated HTTP → claim service | Untrusted snapshots, intents and manifests enter an owner-bound lifecycle. |
| Claim service → repository/PostgreSQL | State transitions and idempotency cross into durable owner-scoped records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-02-01 | Spoofing | Claim owner | critical | mitigate | Session-derived owner, owner predicates and RLS transaction context. |
| T-02-02 | Tampering | Snapshot/manifest | high | mitigate | Zod boundary, immutable digest, ordered manifest and conflict on changed replay. |
| T-02-03 | Repudiation | Callback/claim replay | high | mitigate | User-plus-intent uniqueness, advisory lock, request IDs and durable audit timestamps. |
| T-02-04 | Information disclosure | Cross-owner conflict | high | mitigate | Generic response and no owner/campaign data in public errors. |
| T-02-05 | Elevation of privilege | Project/version ownership | critical | mitigate | Owner tuple FKs, explicit predicates, RLS and PostgreSQL tests. |
| T-02-SC | Tampering | Package installation | high | mitigate | No dependency installation; existing audited workspace only. |
</threat_model>
