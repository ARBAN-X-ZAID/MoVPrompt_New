<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| API/outbox to worker | Duplicate/redelivered jobs cross process and time boundaries and must not create another billable operation. |
| Worker to Vercel Gateway | Untrusted asynchronous responses and ambiguous network outcomes enter the durable lifecycle. |
| Provider output URL to private storage | Capability-bearing remote URLs, DNS answers, redirects, and bytes enter a privileged worker. |
| Final private object to media tools | Untrusted generated bytes enter FFmpeg/FFprobe and must be bounded, quote-checked, and fully decoded before visual review. |
| Internal run/log state to public client | Provider identifiers, errors, URLs, secrets, and retry internals must be removed. |

## STRIDE Threat Register — ASVS Level 1, block on high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Tampering / Repudiation | Provider submit and pg-boss redelivery | critical | mitigate | Stable per-attempt key, persisted opaque operation, database locks, singleton reconciliation, restart/redelivery tests. |
| T-04-02 | Information disclosure / SSRF | Output downloader | critical | mitigate | Exact HTTPS hosts, public DNS filtering, address pinning, every redirect revalidated, bounded body, private object write. |
| T-04-03 | Tampering | Cancellation state | high | mitigate | Immediate release only before provider acceptance; accepted operation remains cancelling/reconciling until confirmed terminal. |
| T-04-04 | Information disclosure | Public DTO and structured logs | high | mitigate | Response allowlist, stable codes, fixture-based redaction verifier, no raw payload or capability-bearing URL logging. |
| T-04-05 | Denial of service | Poll/reconcile scheduling | medium | mitigate | Bounded configurable backoff, pg-boss singleton scheduling, stale-operation observability, no browser timers. |
| T-04-06 | Tampering | Final normalized media | critical | mitigate | Probe and full-decode the stored final object; compare codec/canvas/duration/audio to immutable quote; retain checksum/analyzer evidence. |
| T-04-SC | Tampering | Dependency supply chain | high | mitigate | No package installation; preserve `bun.lock` and verify with `bun install --frozen-lockfile` in the release gate. |
</threat_model>
